# Glossary

This directory contains definitions of the terminology used throughout the **Anteprimicosm Framework**.

The glossary is intended to provide clear, consistent, and carefully worded explanations of the framework's concepts. As the project develops, definitions may be refined to improve precision, clarity, and coherence.

## Purpose

The glossary serves as a reference for readers by:

- Defining key philosophical terms used within the framework.
- Distinguishing original terminology from established philosophical vocabulary.
- Maintaining consistency across the manuscript and supporting documentation.
- Clarifying the intended meaning of concepts as the framework evolves.

## Notes

Some terms in this glossary—such as **Anteprimicosm**, **Primicosm**, and **Harmogenesis**—are introduced as original terminology within this framework. Their definitions reflect the conceptual usage developed in this repository and are not presented as established scientific or philosophical terminology.

Definitions should be understood as part of an evolving philosophical framework and may be revised as the project develops.
